## 🎯 Prompts Prontos para Geração de Imagens

### 1. Inimigo Comum 1: Cangaceiro Espingardeiro (Fases 1, 2 e 3)

* **Conceito:** O típico soldado de infantaria do cangaço. Usa o tradicional chapéu de couro meia-lua com pequenas estrelas de metal, lenço no pescoço, cartucheiras cruzadas no peito, camisa de brim cáqui e empunha uma carabina de repetição.
* **Poses na folha:** 1. Parado em guarda / 2. Mirando rifle / 3. Disparando com clarão no cano / 4. Agachado em cobertura / 5. Derrotado / caindo.

```text
Generate a 16-bit retro arcade pixel art character sprite sheet of a classic 1920s Cangaceiro rifleman enemy from Lampião's gang in the Brazilian Sertão.
Character Details: Traditional brown leather half-moon hat with silver stars, leather vest (gibão), crossed bullet bandoliers on chest, colored neckerchief, khaki work pants, leather sandals (alpercatas), holding a classic Winchester repeating rifle.
Style: Crisp 16-bit arcade pixel art (like Sunset Riders, Wild Guns, Metal Slug) with sharp black outlines and warm sertanejo colors.
Poses arranged horizontally side-by-side in a single row:
1. Idle guard stance with rifle held ready.
2. Aiming rifle directly forward.
3. Firing rifle with muzzle flash and small smoke puff.
4. Crouching low behind cover peeking up.
5. Defeated / knocked back from bullet hit.
Background: Solid pure bright magenta chroma key background (#FF00FF), completely flat with zero shadows on the ground for easy transparency keying.
```

## 🛠️ Como Processar as Imagens no Python / Pygame (Sem alterar o código do jogo)

Quando você gerar as imagens no futuro e salvá-las, basta executar este script de apoio (ou comando equivalente) no terminal para transformar o fundo magenta em transparência e recortar os frames automaticamente:

```bash
python3 -c "
from PIL import Image

def recortar_magenta(caminho_imagem, prefixo, colunas):
    img = Image.open(caminho_imagem).convert('RGBA')
    dados = [ (255, 255, 255, 0) if (r > 180 and g < 70 and b > 180) else (r, g, b, a) for r, g, b, a in img.getdata() ]
    img.putdata(dados)
    w, h = img.size
    largura_frame = w // colunas
    for i in range(colunas):
        sub = img.crop((i * largura_frame, 0, (i + 1) * largura_frame, h))
        bbox = sub.getbbox()
        if bbox:
            sub = sub.crop(bbox)
        sub.save(f'Assets/{prefixo}_{i+1}.png')
        print(f'Salvo Assets/{prefixo}_{i+1}.png')

# Exemplo de uso para uma folha de 5 poses:
# recortar_magenta('Assets/inimigo_lampiao_sheet.jpg', 'lampiao', 5)
"
```
